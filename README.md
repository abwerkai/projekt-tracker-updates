# Projekt-Tracker

Ein einfaches Programm, um alle deine Projekte an einem Ort zu verwalten –
mit Phasen, Status, Priorität, Deadlines, Notizen und Dark Mode.

## Herunterladen & installieren (Windows)

**[Hier zur neuesten Version](https://github.com/abwerkai/projekt-tracker-updates/releases/latest)**

1. Auf der verlinkten Seite unter **"Assets"** die Datei
   **`Projekt-Tracker-Setup-….exe`** anklicken – der Download startet.
2. Die heruntergeladene Datei per Doppelklick öffnen.
3. Windows zeigt beim ersten Mal einen blauen Hinweis
   **"Der Computer wurde durch Windows geschützt"**. Das ist normal bei
   kostenlosen Programmen ohne teure Hersteller-Signatur:
   - Auf **"Weitere Informationen"** klicken
   - dann auf **"Trotzdem ausführen"**
4. Die App installiert sich von selbst, legt eine Desktop-Verknüpfung an
   und öffnet sich. Fertig!

## Deine Daten bleiben bei dir

- Alle Projekte werden **nur lokal auf deinem eigenen PC** gespeichert.
- **Kein Konto, keine Anmeldung, keine Cloud** – nichts wird hochgeladen.
- Jede Person hat ihre **eigene, getrennte** Projektliste. Niemand sieht
  deine Projekte außer dir.

## Updates

Die App meldet sich **von selbst**, wenn es eine neuere Version gibt –
ein Klick genügt, dann lädt und installiert sie sich automatisch.
Du musst nie wieder von Hand herunterladen.

## Sicherung / Umzug

Über den Knopf **"Import / Export"** in der App kannst du all deine
Projekte als Datei sichern und auf einem anderen PC wieder einspielen.
